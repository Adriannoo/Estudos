Normalmente para cada site existem 3 tecnologias fundamentais:
* HTML: O 'jornalista', responsável pelo conteúdo;
* CSS: O 'designer', Responsável por cuidar do estilo e design;
* JavaScript: A parte do programador, responsável pelas interações.
———————————————————————————————————————————————————————————————————————————————————————————
Essas 3 tecnologias funcionam em conjunto! 
E são essas 3 que compõem a parte de cliente da grande maioria dos sites de hoje em dia! 

# Importante lembrar:
 - HTML e CSS NÃO são linguagem de programação, são tecnologias de construção de sites;
 - Já o JavaScript sim, é uma linguagem de programação.
 - Tentar ler bastante!
