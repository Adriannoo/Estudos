Variáveis compostas:
Um array é uma variável que tem vários elementos, cada elemento é composto por seu valor e uma chave de identificação!

.push() - Acrescenta um valor ao final de um array.
.length - Para saber o comprimento. // Sem parênteses.
.sort() - Coloca os valores em ordem crescente.
.indexOf(7) - Vai procurar no vetor o valor 7!
